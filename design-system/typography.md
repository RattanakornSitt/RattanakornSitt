# Polaris Design System

> Typography System

Version 1.0

---

# Philosophy

Typography is not decoration.

It is the primary interface between ideas and people.

Good typography helps people understand information before they consciously realize it.

Every decision should improve readability, hierarchy, and clarity.

---

# Design Goals

The typography system should feel

- Calm
- Confident
- Technical
- Human
- Timeless

Never loud.

Never trendy.

Never distracting.

---

# Typeface

## Primary

IBM Plex Sans

Used for

- Headings
- Body text
- README
- Documentation
- SVG Labels
- UI Components

Why

IBM Plex Sans was designed to bridge engineering precision with human warmth.

It reflects the philosophy of Polaris Design System.

---

## Secondary

Inter

Used only when IBM Plex Sans is unavailable.

---

## Monospace

IBM Plex Mono

Used for

- Code
- File names
- Commands
- Technical annotations
- SVG Coordinates

Never use monospace for paragraphs.

---

# Type Scale

Polaris Design System follows a modular scale.

| Token | Size | Weight | Usage |
|-------|------:|--------:|-----------------------------|
| Display | 56px | 700 | Hero Title |
| H1 | 40px | 700 | Major Heading |
| H2 | 32px | 700 | Section Heading |
| H3 | 24px | 600 | Subsection |
| H4 | 20px | 600 | Small Heading |
| Body-L | 18px | 400 | Intro Paragraph |
| Body | 16px | 400 | Standard Text |
| Body-S | 14px | 400 | Supporting Text |
| Caption | 12px | 500 | Labels / Metadata |
| Code | 14px | 400 | Code Snippets |

---

# Font Weight

| Weight | Usage |
|--------:|----------------------------|
| 700 | Titles |
| 600 | Section Headings |
| 500 | Labels |
| 400 | Body Text |

Avoid unnecessary font weights.

Consistency creates rhythm.

---

# Line Height

| Text | Line Height |
|------|------------:|
| Display | 1.10 |
| Heading | 1.20 |
| Body | 1.60 |
| Caption | 1.40 |
| Code | 1.50 |

Long paragraphs should always prioritize readability.

---

# Letter Spacing

| Usage | Tracking |
|--------|----------|
| Display | -0.03em |
| H1 | -0.02em |
| H2 | -0.01em |
| Body | 0 |
| Caption | +0.03em |
| Code | 0 |

Headings should feel compact.

Body text should remain natural.

---

# Alignment

Default alignment

Left

Avoid centered paragraphs.

Center alignment should be reserved for

- Hero banner
- Quotes
- Open Graph images

---

# Line Length

Ideal

60–75 characters

Maximum

90 characters

Readable typography is more important than fitting more text.

# Hierarchy Principles

People scan before they read.

Typography should answer these questions immediately

1. Where should I look first?
2. What is most important?
3. What can I ignore for now?

If hierarchy is unclear,

improve typography before changing colors.

---

# Readability Checklist

Before publishing

✓ Is the title immediately recognizable?

✓ Can someone scan the page in under 10 seconds?

✓ Is the reading flow obvious?

✓ Are similar elements visually consistent?

✓ Is typography doing the work instead of decoration?

---

# Signature

Typography should disappear.

When people notice the design before the content,

the typography has failed.

The best typography quietly helps people understand.
